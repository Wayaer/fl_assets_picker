## [fl_assets_picker](https://github.com/Wayaer/fl_assets_picker/tree/main/fl_assets_picker)

- 简单封装 `wechat_assets_picker`,`wechat_camera_picker`
- 图库选择支持 android、ios、macos，相机拍摄支持 android、ios

## [fl_image_picker](https://github.com/Wayaer/fl_assets_picker/tree/main/fl_image_picker)

- 简单封装 `image_picker`，支持 android、ios、macos、windows、linux、web
- 视频预览依赖 `fl_video`（基于 `video_player`），Android、iOS、macOS、Web 可用
